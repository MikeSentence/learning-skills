# 提问题库

配套 `SKILL.md`。原则：**要事件，不要评价**。每道题后面标注了「挖什么」和「怎么追」。

难度递进：先问**最近发生的**（记忆清晰、细节多），再问**跨时间的模式**（用于交叉验证）。

---

## 通用杀手锏追问（对任何回答都能用）

这五句是本技能的灵魂，用户答完任何一件事都值得甩一句过去：

1. **"这件事换个水平相当的人来做，他会在哪一步卡住？"**
   → 挖差异化。答不上来＝这件事可能没有独特性，别急着给它贴"能力"标签。
2. **"你刚说的是『我们』，具体哪一步是你做的？"**
   → 拆责任边界。防止把团队成果当个人能力。
3. **"当时还有别的选项吗？你为什么没选？"**
   → 挖决策依据，比"你为什么这么做"更能逼出真实理由。
4. **"如果重来一次，你会在哪一步做不同的决定？"**
   → 挖反思能力，且比"你学到了什么"具体得多。
5. **"这件事里，最让你难受（或最爽）的是哪一段？"**
   → 情绪峰值处就是真实偏好所在，比任何自述都准。

## 一、学识

**问的是"知道自己不知道什么"，而不是"会多少"。**

| # | 问题 | 挖什么 / 怎么追 |
|---|---|---|
| K1 | 最近一次你发现自己不懂，是在什么时候？当时怎么补的？ | 追：补到哪一层停的？是看懂了还是够用了？ |
| K2 | 你最熟的一块知识，讲到哪一层会开始含糊？ | 追：那层下面是什么？你试过往下挖吗？ |
| K3 | 有没有哪块知识你"用过，但没真正搞懂"？ | 敢说出来的那块，往往就是边界。追：为什么一直没补？ |
| K4 | 你学一个新东西，第一步通常做什么？最近一次这么做是什么时候？ | 挖学习路径是否成型。追：这个第一步是怎么形成的？ |
| K5 | 看到一个方案/结论，你什么时候会站起来说"这个不对"？ | 挖判断的触发条件。追：最近一次是什么事？ |
| K6 | 你觉得自己哪块知识的"保质期"快到了？ | 挖自我更新意识 |

## 二、能力

**核心区分：可迁移 vs 岗位绑定。**

| # | 问题 | 挖什么 / 怎么追 |
|---|---|---|
| S1 | 把你最熟的那个东西讲一遍，讲到哪一步你会卡住？ | 卡住的地方＝能力的真实边界 |
| S2 | 你做过的事里，哪一件换个人来做大概率做不成？为什么？ | 直接挖独特性，必配杀手锏追问 1 |
| S3 | 有没有哪件事是"别人觉得很难、你觉得还行"的？ | 挖**被低估的能力**——自己不当事，其实很稀缺 |
| S4 | 反过来，有没有"别人觉得简单、你总是做不好"的？ | 挖盲区。愿意说这条的人很少，值得追问 |
| S5 | 你最近一次从零搞定一个陌生问题是什么时候？怎么搞定的？ | 挖"在没地图的地方走路"的能力 |
| S6 | 你的能力里，哪些换家公司还值钱，哪些离开现在这个位置就没用了？ | **必问题**。直接对应"可迁移 vs 绑定"分类 |
| S7 | 你有没有教过别人什么？讲到哪一步发现讲不下去了？ | 教不下去的地方＝理解不扎实的地方 |

## 三、思维

**给场景，别问风格。** "你的思维方式是什么"是废问题。

| # | 问题 | 挖什么 / 怎么追 |
|---|---|---|
| T1 | 线上服务突然慢了 10 倍，你第一步做什么？为什么第一步做这个？ | 挖排查顺序与假设驱动能力。追：如果第一步就错了，你怎么发现？ |
| T2 | 有人给你一个方案，你判断它靠不靠谱，通常先看哪一点？ | 挖判断的第一反应是"找漏洞"还是"找可行性" |
| T3 | 你最近一次改变对某个技术/某个人的看法，是因为什么？ | 挖什么证据能真正说服他 |
| T4 | 遇到一个完全没头绪的问题，你的第一反应是查、问人、还是先自己想？给个真实例子。 | 挖求助阈值。追：卡多久会去问人？ |
| T5 | 有没有过"所有人都说对，但你就是觉得不对"的时候？后来怎么样了？ | 挖独立判断 + 是否会坚持。追：你当时怎么验证的？ |
| T6 | 你做的决定里，有没有事后证明是错的？当时哪一步判断出了偏差？ | 挖归因方式——归外部还是归自己 |
| T7 | 两个方案各有优劣、时间又紧，你怎么选？举个真实例子。 | 挖在信息不足时的决策风格 |

## 四、态度

**问失败，不问口号。** "你遇到困难会怎样"只会得到标准答案。

| # | 问题 | 挖什么 / 怎么追 |
|---|---|---|
| A1 | 说一次你搞砸的事。事发那一刻，你第一反应是什么？ | 第一反应是甩锅、慌、还是先止损——最真实。追：第二反应呢？ |
| A2 | 有没有一件事你明知道没意义，还是坚持做完了？为什么？ | 挖是"责任感"还是"沉没成本舍不得" |
| A3 | 遇到一个你**必须做但很无聊**的任务，你通常怎么处理？ | 挖对枯燥的耐受力。这条比 A1 更难装 |
| A4 | 你有没有主动接过一件"不在你职责范围内"的事？结果如何？ | 挖主动性是真的还是表演的 |
| A5 | 被否定的时候（方案被毙、意见不被采纳），你一般怎么办？ | 追：会当场争、私下说、还是直接放弃？给例子 |
| A6 | 你上一次"差不多就行"是什么时候？事后后悔吗？ | 挖标准线在哪，以及是否言行一致 |
| A7 | 有没有一件事，你做了很久也没看到结果，还在继续做？ | 挖长周期耐受力 |

## 五、人格

**问具体的冲突，不问"你是什么性格"。**

| # | 问题 | 挖什么 / 怎么追 |
|---|---|---|
| P1 | 跟一个意见完全相反的人合作，你会怎么处理？给个真实例子。 | 挖冲突模式：硬刚 / 迂回 / 回避 / 升级 |
| P2 | 团队里你通常是提想法的人、执行的人、还是挑毛病的人？ | 追：这三种你分别占多少？有没有例外的时候？ |
| P3 | 你什么时候会主动找人帮忙？什么时候宁可自己死磕？ | 挖求助的边界。追：死磕到什么程度会放弃？ |
| P4 | 你觉得自己最难相处的是哪类人？为什么？ | 反向定义自己。追：如果必须跟这类人合作一年，你怎么办？ |
| P5 | 别人对你最常见的误解是什么？ | 挖"自我认知 vs 他人认知"的差距 |
| P6 | 连续加班两周 vs 一直做没挑战的事，哪个更让你难受？ | 挖真正的能量杀手是什么 |
| P7 | 你是从做事里获得能量，还是从跟人聊里获得能量？ | 粗略的内外向判断，用于理解工作偏好 |

## 六、理想

**看代价，不看愿望。** 这一维度最容易得到漂亮话，所以提问方式要绕。

| # | 问题 | 挖什么 / 怎么追 |
|---|---|---|
| V1 | 过去一年，有哪些事是**没有人要求你**、你自己去做的？ | **本维度最重要的一题**。真动机在这里，不在"我想成为"里 |
| V2 | 如果明天不用上班，你第一件想做的事是什么？为什么现在没做？ | "为什么现在没做"才是重点——挖阻碍是真实的还是借口 |
| V3 | 五年后，你希望别人怎么向别人介绍你？ | 挖想要的身份标签 |
| V4 | 你愿意为了做成某件事，放弃什么？具体一点。 | **必问**。答不出代价的＝幻想，标 `[幻想待验证]` |
| V5 | 有没有什么事是你现在不做、十年后一定会后悔的？ | 挖长期优先级，通常比 V3 更诚实 |
| V6 | 你最不能接受的工作状态是什么？ | 挖底线。底线比目标更能定义人 |
| V7 | 你羡慕的人是谁？羡慕他哪一点？那一点你自己有吗？ | 追"自己有没有"——有，说明是想要放大；没有，说明是缺口 |

## 提问节奏建议

一轮 3-5 题，推荐组合：

- **第一轮**（破冰，最容易答）：`K1 / S5 / V1` —— 都是"最近一次"，记忆清晰
- **第二轮**（往深走）：`S2 / A1 / T1` —— 加杀手锏追问 1
- **第三轮**（硬骨头）：`S4 / A6 / V4` —— 这些题不好答，允许跳过
- **收尾**（交叉验证）：`S6 / V6 / P5` —— 用来检验前面提炼的标签

**不要一次问完六个维度。** 一个维度一轮，用户确认提炼卡后再进下一个。
